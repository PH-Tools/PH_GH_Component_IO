# ph_gh_component_io/ — the package

Shared I/O plumbing for PH-Tools Grasshopper components. IPy2.7-safe. See `../context/ARCHITECTURE.md`.

## Modules

- `gh_io.py` — the `IGH` interface (hides Rhino/GH/`ladybug_rhino` API), `ComponentInput`/`ComponentOutput`, and input/output wiring helpers. The core.
- `input_tools.py` — input cleaning/conversion (`input_to_int`, `clean_get`, `clean_tree_get`, `memoize`).
- `preview.py` — `object_preview` for canvas pretty-printing. (`output_tools.py` is a legacy duplicate — keep importable.)
- `validators.py` — `Validated` descriptor base + concrete validators (`NotNone`, `HBName`, `IntegerNonZero`, `Float`, …).
- `run_subprocess.py` — run a CPython subprocess from an IronPython component (heavy-compute dispatch).

## Notes
- Public API (`IGH`, input helpers, validators) is a contract for the plugin repos — treat signature changes as breaking. See `../context/CODING_STANDARDS.md`.
- No `tests/` yet (CI looks for one) — an open item in `../planning/STATUS.md`.
